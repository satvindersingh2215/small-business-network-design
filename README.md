# Small Business Network Design

A Cisco Packet Tracer network design project focused on building and configuring a segmented small-office network.

## Project Overview

This project demonstrates a small-business network with separate departmental VLANs, IPv4 addressing, DHCP, and inter-VLAN routing.

## Network Features

- Departmental VLAN segmentation
- IPv4 subnetting and address allocation
- Router-on-a-stick inter-VLAN routing
- DHCP configuration for client devices
- Switch access ports and 802.1Q trunking
- Network connectivity testing and troubleshooting

## Technologies

- Cisco Packet Tracer
- Cisco IOS CLI
- VLANs and trunking
- IPv4 networking
- DHCP
- Inter-VLAN routing

## Project Files

- `.pkt` — Packet Tracer network simulation

## Verification

Connectivity and configuration tests will be documented as they are completed.

## Learning Outcomes

- Understand small-office network architecture.
- Configure VLANs and trunk links.
- Apply IP addressing and default gateway settings.
- Troubleshoot connectivity between network segments.
- Explore network segmentation and security practices.
